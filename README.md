## 📖 Descrizione
Dataset NSL-KDD (25k connessioni rete): identifico top 8 attacchi, EDA e visualizzazioni executive.

**Obiettivo CV:** Data cleaning, Pandas/Matplotlib per junior data analyst cybersecurity.
## 🛠 Tech Stack
- Python 3.9+, Pandas, Matplotlib
- Dataset: NSL-KDD (Kaggle)

## 🚀 Installazione
```bash
git clone https://github.com/Suzuka90/CyberSec-DataAnalyzer.git
pip install pandas matplotlib jupyter
jupyter notebook 
```
